# X 文字陀螺競技場

手機、平板及電腦瀏覽器都能遊玩的雙人同機 2D 文字／手繪陀螺對戰遊戲（v1 試玩版）。

## 玩法

1. 玩家 1（藍色）及玩家 2（紅色）分別在左右編輯區選擇「輸入文字」或「自由手繪」。
2. 調整發射力量、發射角度及旋轉方向。
3. 按「⚡ 3・2・1 發射！」，兩顆陀螺同步進入中央競技盤自動對戰。
4. 觸碰外圍 X 加速軌會衝向對手；被擊飛或先停轉即判負。
5. 可重新準備下一局或清除比分。

## 如何執行

直接用瀏覽器開啟根目錄的 `index.html`。不需要伺服器、安裝工具或額外程式庫。

要公開提供手機遊玩，可將此倉庫設定為 GitHub Pages：

1. 在 GitHub 新建 **Public** repository。
2. 將 `index.html`、`README.md` 上傳到預設分支根目錄。
3. 前往 **Settings → Pages → Build and deployment**，來源選 **Deploy from a branch**，分支選 **main**、資料夾選 **/(root)**，按 **Save**。
4. 公開網址通常為 `https://<你的GitHub帳號>.github.io/<倉庫名稱>/`；等待 GitHub Pages 顯示已發布後再開啟。

## 現有功能

- 雙人同機、文字輸入或觸控／滑鼠繪圖
- 畫筆、橡皮擦、圓形、星形、復原、清除
- 由圖案近似分析攻擊、防禦、持久力
- 發射力量、角度、左右旋轉
- 2D 競技盤、X 加速軌、碰撞、擊飛、停轉、比分、音效切換
- 手機響應式排版

## 開發範圍

本作品為非官方的原創 2D 模擬試玩版。圖案影響能力數值，但碰撞仍採簡化物理模型，**不是逐像素／逐尖角碰撞**。目前不包含兩支手機連線對戰，也不是 3D 遊戲。
