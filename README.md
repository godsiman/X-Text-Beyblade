# X 文字陀螺競技場

手機、平板及電腦瀏覽器都能遊玩的支援單人挑戰 NPC／雙人同機的 2D 文字與手繪陀螺遊戲（v1.2）。

## 玩法

1. 選擇「🎮 單人 VS 電腦」或「👥 雙人同機」。
2. 單人：左側輸入文字／自由手繪；右側 NPC 自動採用中文字／詞組、英文字母 A–Z、英文單詞／詞組或制式幾何圖案。可以指定 NPC 造型種類、難度，或按「換一個 NPC」。
3. 雙人：左右兩位玩家分別設計文字或手繪陀螺。
4. 玩家可調整發射力量、角度與旋轉方向；NPC 會依照選擇的難度自動設定發射參數。
5. 按「⚡ 3・2・1 發射！」開始對戰。X 加速軌會觸發衝刺；擊飛出界、停轉或回合時間結束時判定勝負。
6. 單人模式每次按「再戰」都會生成不同 NPC，保留比分。

## 如何執行

直接用瀏覽器開啟根目錄的 `index.html`。不需要伺服器、安裝工具或額外程式庫。

要公開提供手機遊玩，可將此倉庫設定為 GitHub Pages：

1. 在 GitHub 新建 **Public** repository。
2. 將 `index.html`、`README.md` 上傳到預設分支根目錄。
3. 前往 **Settings → Pages → Build and deployment**，來源選 **Deploy from a branch**，分支選 **main**、資料夾選 **/(root)**，按 **Save**。
4. 公開網址通常為 `https://<你的GitHub帳號>.github.io/<倉庫名稱>/`；等待 GitHub Pages 顯示已發布後再開啟。

## 現有功能

- 單人 VS NPC / 雙人同機，文字輸入或觸控／滑鼠繪圖
- NPC 擴充字庫（中英文詞組、A–Z 字母分開）、六芒星、齒輪、三角、六角盾、雙環、渦流、十字等制式圖案
- NPC 難度（新手／一般／高手）、隨機更換對手、每局自動換對手
- 畫筆、橡皮擦、圓形、星形、復原、清除
- 文字對應特效：RUSH 追擊、CAMP 守中、FIRE／火 灼燒、龜減傷、速度加速、大增加重量；另有冰、雷、旋風
- 離線詞典支援中英文技能與雙技能組合，並針對「火車」「大海」等常見詞避免誤判
- 由圖案近似分析攻擊、防禦、持久力
- 發射力量、角度、左右旋轉
- 2D 競技盤、X 加速軌、碰撞、擊飛、停轉、比分、音效切換
- 手機響應式排版

## 開發範圍

本作品為非官方的原創 2D 模擬試玩版。圖案影響能力數值，但碰撞仍採簡化物理模型，**不是逐像素／逐尖角碰撞**。目前文字辨識使用**離線詞典與規則**，不是通用 AI 語意理解；未知字詞仍按文字外形計算能力。若需任意詞都能理解，須另建安全的雲端 AI 服務，不能把 API 金鑰放在公開 HTML。NPC 是本機電腦對手，**不是雲端 AI**；不包含兩支手機連線對戰，也不是 3D 遊戲。
